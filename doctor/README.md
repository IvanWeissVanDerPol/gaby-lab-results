## Filosofía

No somos el médico. Estos documentos:

1. **Listan** los valores fuera de rango (los del propio laboratorio)
2. **Citan** las fuentes (siempre los PDFs del laboratorio)
3. **Sugieren preguntas** que el médico puede responder con contexto clínico
4. **No recomiendan** tratamientos, dosis, ni diagnósticos

Si el médico dice "esto es normal" o "no se preocupe", eso gana sobre cualquier cosa acá.
